# Difference from the public demonstration

The public repository is a shareable, fictional workflow demonstration. Its GitHub Pages build uses browser storage and a simulated API. Its local Node option demonstrates real requests but has freely selectable sample personas.

The private edition adds separate production-mode identity and membership checks, provider-scoped identity bindings, private evidence storage, audit history, roster administration, CSRF-protected sessions, and an encrypted Canvas OAuth connector. It preserves demo mode for testing.

Production credentials, real academic records, and local database/upload files are not part of the source repository. Live university integration remains an explicit configuration and verification step.
